/ ARCHITECTURE CASE STUDY

MediSync: Edge-Native Smart Clinic Appointment Platform

How a unified Cloudflare Workers architecture combined Hono and React 18 to eliminate CORS roundtrips, cut edge latency to <15ms, and prevent appointment double-booking.

Role Full Stack Architect
Environment Cloudflare Workers & D1
Frontend React 18 + TanStack Query
Testing 16 Vitest Suites (CI/CD)
Latency <15ms Global Edge
/ 01 THE CHALLENGE

Eliminating CORS Roundtrips & Concurrency Collisions

Traditional full stack clinic booking applications often run separate frontend and backend hosting domains, introducing high-latency cross-origin preflight requests (OPTIONS) and risking booking collisions when multiple patients click to reserve the same doctor slot simultaneously.

The goal was to design an edge-first healthcare platform that eliminated these roundtrips entirely, provided instant UI feedback, and handled concurrency at the database level rather than through fragile client state.

/ 02 THE SOLUTION

Unified Worker Deployment & SQLite Partial Unique Index

I engineered MediSync to serve both the Hono REST API and static React 18 assets from a single Cloudflare Worker. Because both API and assets share the same edge origin, CORS preflights are completely avoided, achieving sub-15ms edge latency across global regions.

To eliminate appointment double-booking, I implemented a SQLite partial unique index in Cloudflare D1. Even when parallel requests arrive in the exact same millisecond window, the database rejects duplicates with an automatic 409 Conflict status.

// SQLite D1 Partial Unique Index Definition
CREATE UNIQUE INDEX IF NOT EXISTS idx_active_doctor_slot
ON appointments (doctor_id, slot_timestamp)
WHERE status NOT IN ('cancelled', 'rejected');

// Verified through automated parallel request collision test suites
/ 03 SECURITY & SCHEDULING

WebCrypto PBKDF2 & Dynamic Slot Algorithms

Security is enforced using the native WebCrypto API with PBKDF2 (SHA-256) password hashing and role-based JWT authorization separating Admin, Doctor, and Patient permissions. D1-backed rate limiting protects sensitive endpoints against automated attacks.

The platform features a dynamic scheduling algorithm that calculates available 30-minute consultation slots on the fly from weekly doctor recurring schedules, doctor leave exceptions, and existing reservations.

/ 04 RESULTS & IMPACT

Performance Verification

  • Sub-15ms edge response: Verified via real-time edge telemetry.
  • 16 Vitest suites: Continuous integration pipeline on GitHub Actions passing 100% of collision tests.
  • Zero double-booking: 100% collision resistance verified under synthetic stress testing.
